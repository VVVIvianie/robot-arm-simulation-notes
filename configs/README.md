# 小型对照配置草案

`pilot.template.json` 用来记录将来要试的相机设置，不能直接启动仿真。环境、机器人、场景和相机参数仍为空。

暂定三个条件：原始安装、原始相机局部 x 轴 +5 cm、局部 y 轴 +15°。幅度参考师兄提供的材料，轴与正方向是待验证建议；[来源说明](../docs/provenance.md) 保留了归属。

使用列向量，`T_E_Cw_changed = T_E_Cw_original @ Delta`。`Delta = [R, t; 0, 1]` 先旋转后平移；光学坐标暂定 x 右、y 下、z 前。实际使用时须核实模拟器坐标与单位。

先比较同一场景状态下的真实图像，并记录遮挡和目标可见性。本阶段不要求策略模型、训练或成功率评测。
