# 最小模拟实验的操作说明

**状态：最小演示已在助手环境运行。** 目标是观察相机视角变化，不预设模型性能结论。参考来源见 [来源说明](provenance.md)。

## 先把一个场景跑通

选择一个实际能运行的环境和机械臂场景，保存启动命令、软件版本、初始状态与一张真实截图。环境检查脚本只能列出包信息，不能替代这一步。

## 做一个小对照

- 记录默认相机位置、朝向、分辨率和机器人初始状态。
- 尽可能复用同一个场景状态，分别采集默认视角、单轴平移、单轴旋转的图像。
- 当前配置草案是局部 x 轴 +5 cm、局部 y 轴 +15°；轴、正负方向和幅度均需在环境中检查可行性。
- 若使用 wrist camera，保持它随明确的末端 link 运动；每次采集记录实际相机位姿。
- 检查目标是否出画、被遮挡或两路图像不同步。不要把这些情况忽略掉。

## 坐标记录

采用列向量，`T_A_B` 表示把 B 坐标变换至 A。配置中的平移单位为米，角度为度；使用模拟器时显式换算。

```text
T_B_Cw(t) = T_B_E(t) @ T_E_Cw
T_E_Cw_changed = T_E_Cw_original @ Delta_local
```

相机光学坐标暂定 x 向右、y 向下、z 向前；模拟器的原生坐标不同则先转换。上述右乘扰动在原始相机局部坐标中表达。实际移动相机时更新其几何记录，不同时加入错误标定。

## 留下哪些结果

每次记录使用的代码版本、命令、配置、输出路径、成功或报错，以及图像中的具体变化。已有结果见 [首次记录](../results/example/record.md)。用户复现步骤见 [运行指南](quickstart.md)。

截图和预编程机械臂动作只能用于说明仿真及采集情况，不能据此声称验证了 VLA 鲁棒性。只写自己实际观察到的现象与局限。
