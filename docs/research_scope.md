# 机械臂仿真实验范围

## 当前目标

本仓库用于保存个人机械臂仿真的学习代码、实验参数和实际观察。助手已在 Linux CPU 环境完成 64 帧四视角演示；用户已在 Colab 完成 30 帧双视角快速演示，并提供 GIF、PNG、源码和元数据，现已核对其一致性。分别见 [助手记录](../results/example/record.md) 与 [用户实际记录](../results/user_colab/20261127T044151Z/record.md)。用户随后完成了 [光学局部 +x 平移 5 cm 的相机对照](../results/user_colab/20261127T054546Z_shift_x5cm/record.md)，五个原始文件已核对。按用户要求，两次小型仿真至此收尾，当前只整理组会汇报，不继续追加实验。

先尝试一个简单场景：一个机械臂、一个固定外部相机和一个随末端运动的相机。理解两路图像与相机位置的关系，再按实际条件做少量对照。

## 本次可以记录什么

| 内容 | 记录要求 |
| --- | --- |
| 自己实现或修改的代码 | 写明用途；采用第三方代码时保留来源与许可信息 |
| 实验参数 | 明确环境、任务、相机位置、随机种子及实际运行方式 |
| 图像和日志 | 保留产生它们的配置，记录失败及中断 |
| 观察和理解 | 区分直接观察、个人解释与尚待验证的猜测 |

## 完成状态

环境能够启动，只能说明环境初步可用；保存双视角图像，只能说明采集流程运行过。任务或策略表现需要对应的真实运行记录，未执行部分保持“待开始”。
