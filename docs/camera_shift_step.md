# 下一步：只改变手腕相机的横向安装位置

目标是观察一个参数如何改变图像：同一机器人状态下，比较原始手腕相机与沿其光学局部 +x 方向平移 5 cm 的相机。两者朝向一致。场景、机器人控制、物理步进、投影参数及采样时序保持相同。

## 现在怎么做

1. 回到刚才生成双视角动图的同一个 Colab 笔记本。
2. 在原有代码格下方点击“+ 代码”。

5. 本次结果会打包为新的 ZIP 并调用下载。把新动图和 `metadata.json` 发来核对；也可以直接发送下载的 ZIP。

此代码格复用上一格已经准备好的 Python 环境，并通过 SHA-256 选取已核查版本的原始脚本。如果 Colab 运行时已经清空，先重跑最初生成双视角动图的代码格。

每次运行使用新的 `shift_x5cm_日期时间/` 目录。此前的 `run_...` 结果不变；新目录中的 `demo.py` 是本次实际执行代码，`metadata.json` 记录两路相机状态，`derivation.json` 记录来源及唯一对照因素。

## 应该观察什么

相机光学 +x 方向是相机自身的右方。对同一时刻、位于两相机前方的同一个空间点，理想针孔模型下：

```text
u_shifted = u_baseline - fx * 0.05 / Z
v_shifted = v_baseline
```

因此这次主要观察水平方向的变化：相机向右平移时，物体投影向左移动。实际渲染还包含物体表面、遮挡、边界裁切及像素取整，最终以输出图像为准。

纯横向偏移不会直接修正红色方块的下边缘裁切。当前任务是理解相机横向移动与图像位置的关系，不预先把对照解释成改进。
